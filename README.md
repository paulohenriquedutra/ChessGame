♟️ Chess Game — Java & Maven

Projeto de xadrez clássico desenvolvido em Java, com estruturação usando Maven e foco em boas práticas de Programação Orientada a Objetos.
O jogo é voltado para dois jogadores locais, sem utilização de inteligência artificial.

🚀 Destaques do Projeto

Arquitetura organizada com Maven

Código estruturado seguindo princípios de POO

Lógica completa de movimentação das peças

Validação de jogadas

Alternância de turnos (Brancas x Pretas)


🛠️ Tecnologias

Java

Maven

[⬇️ Download](https://github.com/paulohenriquedutra/ChessGame/releases)


🎯 Objetivo

Demonstrar Conhecimento da linguagem Java, modelagem de classes, organização de projetos e lógica de jogos, com foco em aplicações desktop.
